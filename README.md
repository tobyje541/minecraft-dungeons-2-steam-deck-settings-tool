## 🎛️ Understanding the Setting Groups

The tool divides settings into four broad groups so you always know where to look.

**Performance group** covers anything that affects how smoothly the game runs. This includes quality levels, effects density, and the trade-offs between visual polish and responsiveness.

**Display group** covers everything about how the image reaches your eyes: resolution, scaling behavior, brightness, and framing.

**Control group** covers input. This includes controller button arrangements, sensitivity, and the small adjustments that make a gamepad feel natural in your hands.

**System group** covers the platform-level notes, including SteamOS configuration reminders and Windows-level options that interact with the game.
